## 🚀 Featured Projects

A collection of enterprise-grade systems I built and maintain in production — most running behind a single internal portal at [codium.my.id](https://codium.my.id).

### 🔐 Identity & Access

**SSO — Single Sign-On** · `Laravel` `REST API` `Redis`
> Centralized authentication service for all internal apps. TOTP 2FA, email verification, role & permission management, Sunfish HR sync, and a REST API consumed by web & mobile clients.

**VERA — Virtual Exit & Resignation App** · `Laravel 12` `Tailwind` `Redis` `DomPDF`
> Digital exit clearance & resignation workflow with multi-level approval, auto employee sync from Sunfish HR, scheduled backups, and PDF document generation.

### 🎫 Helpdesk & HR

**IT Helpdesk (Form CR)** · `Laravel 13` `MySQL` `Vite`
> Ticketing & change-request system for IT with multi-level approval workflow and status tracking.

**HRD Support (Form CR)** · `Laravel 13` `MySQL` `Vite`
> HR ticketing & request forms with multi-division approval workflow.

**OneGate Personalia (IntraSupply Hub)** · `Laravel 13` `Tailwind` `Alpine.js` `Spatie`
> Employee equipment management — uniform/PPE requests, approval workflow, multi-warehouse inventory, stock opname & full audit trail.

### 📊 Monitoring & Infrastructure

**Dashboard Monitoring DN** · `Laravel 13` `Vite`
> Delivery Note / Delivery Order monitoring with automatic SAP synchronization.

**Dashboard Monitoring Mikrotik** · `Laravel 13` `Vite`
> Network device monitoring dashboard (accessible via Tailscale).

**Monitoring CCTV** · `MediaMTX` `WebRTC` `HLS` `nginx`
> Real-time CCTV streaming via WebRTC with HLS fallback, served over Cloudflare Tunnel.

### 🌐 Content & Web

**MediaBox** · `Laravel 13` `Vite`
> Digital asset & internal documentation archive management.

**GKP Sinode Jawa Barat** · `Laravel 12` `Blade`
> Church website — news, service schedules, contact & donation support module.

**Portal Aplikasi Internal** · `PWA` `HTML` `CSS`
> Single landing page to access every internal app in one place.

**Maintenance Mode** · `PHP` `Static`
> Centralized maintenance-mode page shared across all production apps.
